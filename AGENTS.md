# Graphics repository guidance

Bounded graphics decode extension crate (landed CTX-0003, independently verified CTX-0004). Read repo.toml, TODO, CarryCtx and accepted rich/image/security contracts in the root docs checkouts. Core retains bounded protocol intake, placement/resource policy and renderer validation. Decoders require bounded dimensions/stride/output, deadlines, memory limits and crash recovery; separate crates are not isolation.

English only; no hardcoded host/environment values. Rust starts 0.0.1, edition 2024, Core MSRV. Use just gates; metadata validation is not product evidence. CTX-0001 -> 0002 -> 0003 -> 0004: bootstrap, approved contracts, implementation, independent acceptance. Named sessions, narrowed scopes and task worktrees after first commit. Managed hooks required; no commit/push/release without authority. Direct bootstrap is user-authorized, not independent review. Publish only redacted snapshots, never DB/local refs. Preserve unrelated work; no silent installs, process kills or destructive cleanup. Require malformed-input, quota, timeout and renderer rejection evidence plus canonical docs synchronization.
